# Codex Cloud handoff: Molten Lavamancer

## Task and behavior

The original Developer-track request targeted Argivian Blacksmith, with permission to choose another candidate if that work was out of scope. The current candidate is **Molten Lavamancer**. Its printed trigger says that whenever a source you control deals noncombat damage to one or more opponents **during your turn**, you create **one 1/1 red Elemental token**; it triggers only once each turn. Prowess also remains present. Simultaneous damage to two opponents is one qualifying event, while a separate damage event can trigger again only if the printed cap is absent.
